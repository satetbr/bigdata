# Dashboard de Prospeccao - Censo 2010

Projeto de Power BI que transforma dados do Censo 2010 em um dashboard para apoiar a prospeccao de clientes da empresa de cursos preparatorios. O foco e indicar bairros com maior potencial de alunos, com filtros por provas.

## Objetivo
Identificar bairros com maior concentracao de possiveis clientes para a Unibe, usando informacoes do Censo 2010 e filtros de provas para segmentar o publico.

## Fonte de dados
Dados do Censo 2010 (dados publicos) tratados para gerar indicadores e facilitar a leitura no dashboard.

## Como abrir
1. Abra o **bigdata.pbix** no Power BI Desktop, ou
2. Abra o **bigdata.pbip** (Power BI Project) no Power BI Desktop para trabalhar com o projeto em formato PBIP.

## Como usar o dashboard
- Use os filtros de **provas** para segmentar o publico.
- Analise os bairros com maior potencial de captacao conforme os indicadores exibidos.
